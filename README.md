# 문장 분리기

TRPG 시나리오 글을 붙여넣으면 문장 단위로 나눠 주고, 누르기만 하면 복사되는 도구입니다.

- **그냥 쓰기**: `index.html` 을 더블클릭하면 바로 열립니다. (인터넷이 없어도 작동, 글꼴만 기본 글꼴로 보여요)
- **사이트로 쓰기**: 아래 순서대로 깃허브에 올리면 `https://아이디.github.io/저장소이름/` 주소로 어디서든 열 수 있습니다.

---

## 깃허브 사이트로 올리기 (처음 한 번)

1. [github.com](https://github.com) 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** 버튼 → **New repository**.
3. **Repository name** 에 영어로 이름을 적습니다. 예: `munjang`
   - 아래에서 **Public** 을 고릅니다. (무료 계정은 Public 저장소만 사이트로 만들 수 있어요)
   - **Create repository** 를 누릅니다.
4. 만들어진 화면에서 **uploading an existing file** 글자를 누릅니다.
   (안 보이면 **Add file → Upload files**)
5. 이 폴더 안의 것들을 **전부** 끌어다 놓습니다.
   - `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, 그리고 **`icons` 폴더 통째로**
   - 맨 아래 초록색 **Commit changes** 를 누릅니다.
6. 저장소 위쪽 메뉴의 **Settings** → 왼쪽 메뉴에서 **Pages**.
7. **Build and deployment** 칸에서
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` , 폴더는 `/ (root)` → **Save**
8. 1~2분쯤 기다린 뒤 같은 Pages 화면을 새로고침하면 맨 위에 주소가 나옵니다.
   `https://아이디.github.io/munjang/` ← 이 주소를 즐겨찾기 해 두세요.

## 고친 파일을 다시 올릴 때

**Add file → Upload files** 에서 바뀐 파일만 끌어다 놓고 **Commit changes**.
같은 이름이면 덮어써집니다. 1~2분 뒤에 사이트에 반영돼요. (바로 안 바뀌면 새로고침 한 번 더)

## 내 글은 어디에 저장되나요?

- 쓴 글은 **깃허브에 올라가지 않습니다.** 지금 쓰는 브라우저 안에만 저장돼요.
  사이트 주소는 누구나 열 수 있지만, 다른 사람이 열면 빈 화면입니다.
- 왼쪽 **저장** 칸에서 이름을 붙여 저장해 두면, 창을 닫을 때마다 같은 이름으로 자동 저장됩니다.
- 브라우저 기록을 지우거나 다른 컴퓨터에서 열면 안 보여요. 중요한 작업은 **HTML로 저장** 으로 파일을 받아 두세요.
- **예전 파일에서 하던 작업 옮기기**: 예전 `sentence-splitter.html` 을 열고 **HTML로 저장** →
  사이트에서 **파일 불러오기** 로 그 파일을 고르면 그대로 넘어옵니다.

## 앱처럼 설치하기 (선택)

사이트 주소로 연 뒤, 크롬·엣지 주소창 오른쪽의 **설치 아이콘** 을 누르거나 **⋮ 메뉴 → 설치** 를 고르면
바탕화면/작업표시줄에 아이콘이 생기고 따로 창으로 열립니다. 인터넷이 끊겨도 열려요.

## 폴더 안의 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 (이것 하나만 있어도 작동) |
| `manifest.webmanifest` | 앱 이름·아이콘 정보 (설치용) |
| `sw.js` | 인터넷이 끊겨도 열리게 해 주는 도우미 |
| `icons/` | 앱 아이콘 |
| `README.md` | 이 설명서 |

## 바뀐 점 (2판)

- 긴 문장은 4줄까지만 보이고 **더 보기** 로 펼침 (⋯ 메뉴에서 끄기)
- 서식 기호: `**굵게**`, `==형광펜==`, `> 메모 줄`(복사할 때 빠짐), `- 목록 줄`
- 단축키: `Ctrl+B` 굵게, `Ctrl+E` 형광펜, `Tab`/`Shift+Tab` 들여쓰기, `Esc` 편집 끝내기·선택 해제
- 우클릭 메뉴를 하위 메뉴로 정리 (캐릭터 ▸, 서식 ▸, 폴더 ▸)
- 사이드바를 접히는 칸으로 정리, 위쪽에 도구줄(편집/복사 전환, ⋯ 메뉴)
- 브라우저 기본 팝업 대신 화면 안의 확인 상자·알림
- 여러 줄 선택 시 아래에 "N개 선택됨" 표시
- 깃허브 사이트·앱 설치 지원
